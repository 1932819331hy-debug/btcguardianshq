BtcGuardiansHQ
Preserving one of the last surviving full-archive Bitcoin nodes from 2009 (original Berkeley DB 4.8.30 wallet, birthtime 1, never restored) and i am curently building self-sovereign tools from its historical data. Continuous lineage for over 17 years, self-funded.
Special thanks to the mempool.space team as this project is proudly forked from their incredible open-source explorer. Mempool.space is the gold standard for Bitcoin visualization, and their work made this local project possible. Huge praise and gratitude!
Features
Genesis Node: Full archive since 2009, Tor-routed, outbound-only for privacy.
Local-Only Mempool Explorer: Live visualization powered directly by the genesis node (no external APIs).
Non-Custodial Vault Tools: Air-gapped signing and inheritance planning (prototype demo created Dec 13, 2025).
All privacy-first, fully open-source.
Proof of Genesis
Wallet birthtime: 1 (pre-timestamp era).
Early shards: Receives from 2011–2012 (poker era), total lifetime ~0.257 BTC (now spent, history preserved).
Block 1 stats: Verified first mined block with Satoshi's message.
Node traffic: Live graphs showing healthy activity.
